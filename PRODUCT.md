# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

MkDocs + Material for MkDocs, déployé sur GitHub Pages (`mkdocs gh-deploy`, branche `gh-pages`). Contenu en Markdown dans `docs/`, interactivité en JavaScript vanilla dans `docs/javascripts/`, styles dans `docs/stylesheets/`.

## Users

Étudiants de L1 à l'Université Amadou Mahtar Mbow (UAM, Sénégal), cours « Évolution et Écosystème Web » de Dr Mariame Niang (2025-2026). Ils découvrent le HTML, révisent pour les examens et refont les exercices de TP. Ils lisent d'abord sur téléphone ; s'ils sont convaincus, ils ouvrent le site sur PC pour pratiquer. Les deux doivent être excellents.

## Product Purpose

Manuel HTML numérique écrit par un étudiant pour ses camarades. Il reprend fidèlement le cours, le rend lisible, et permet de voir immédiatement le rendu de chaque exemple et de s'exercer avec une correction instantanée.

## Positioning

Contextualisation stricte : uniquement ce qui a été vu en classe (support de Dr Niang), dans le style d'écriture du cours (HTML classique, balises en majuscules, attributs de présentation comme `BGCOLOR`, `ALIGN`, `<FONT>`). Les coquilles du support sont signalées poliment avec la bonne écriture. Ce que les milliers d'autres tutoriels HTML ne peuvent pas copier.

## Operating Context

Lecture mobile entre les cours, pratique sur PC (salle TP, Visual Studio Code ou Bloc-notes + navigateur). Révisions avant examen. Connexion correcte.

## Capabilities and Constraints

- Aperçu instantané du rendu de chaque exemple, modifiable en direct.
- Exercices avec éditeur et vérification automatique, progression gardée localement.
- Quiz rapides par chapitre.
- Chapitre Formulaires conservé en bonus, marqué hors programme (absent du support).
- Pas d'ajout de notions hors cours.

## Brand Commitments

Nom : « Manuel HTML ». Auteur : Flamme (cuttyflam04). Langue : français. Fidélité au vocabulaire du cours.

## Evidence on Hand

Support de cours PDF de Dr Niang (98 pages, `E:\Campus\HTML\cours_html 1 UAM 2026.pdf`). Aucun témoignage ni statistique d'usage : ne pas en inventer.

## Product Principles

1. Le cours d'abord : rien qui ne soit dans le support, sauf mention claire « hors programme ».
2. Voir pour comprendre : chaque bout de code montre son rendu.
3. Pratiquer avec retour immédiat.
4. Lisible sur téléphone, confortable sur PC.
