## Comment travailler avec ce manuel

1. **Lisez** un chapitre dans l'ordre : il suit exactement le support de cours.
2. **Modifiez** les exemples : cliquez sur *Modifier le code*, le rendu suit.
3. **Faites les exercices** : la liste de vérification se coche toute seule. Votre code est gardé dans ce navigateur, vous pouvez revenir plus tard.
4. **Refaites-les dans Visual Studio Code**, en vrai, avec un fichier `.html` ouvert dans votre navigateur.

!!! support "Les encadrés « Dans le support de cours »"

    Le support contient quelques coquilles, comme `<rt>` au lieu de `<tr>`. Ces encadrés donnent la bonne écriture, pour ne pas se faire piéger le jour de l'examen. Elles sont toutes regroupées dans l'[annexe C](manuel/annexes/annexe-c.md).
