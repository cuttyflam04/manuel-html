# Bienvenue

Bienvenue dans la version numérique du **Manuel de HTML**.

Cette plateforme a été conçue pour accompagner les étudiants dans l'apprentissage du **langage HTML**, première étape indispensable vers le développement Web.

Contrairement à un simple document PDF, cette version propose une navigation rapide, une recherche intégrée, des exemples de code lisibles et une organisation permettant d'accéder facilement à chaque notion.

Que vous soyez débutant ou en phase de révision, ce manuel a pour objectif de vous guider progressivement jusqu'à la maîtrise des bases du HTML.

---

## Objectifs pédagogiques

À l'issue de ce manuel, vous serez capable de :

- Comprendre la structure d'une page HTML.
- Utiliser correctement les principales balises HTML.
- Créer des listes, des tableaux et des formulaires.
- Insérer des images et créer des liens hypertextes.
- Mettre en forme une page à l'aide des attributs HTML classiques étudiés en travaux pratiques.
- Réaliser une page Web complète respectant une structure cohérente.

---

## Comment utiliser cette documentation

Cette plateforme est conçue pour être utilisée aussi bien en cours qu'en autonomie.

Nous vous recommandons la progression suivante :

1. Lire les chapitres dans leur ordre.
2. Reproduire les exemples dans votre éditeur de code.
3. Tester les résultats dans votre navigateur.
4. Réaliser les exercices proposés.
5. Utiliser la barre de recherche pour retrouver rapidement une balise ou une notion.

---

## Exemple de page HTML

Toutes les pages HTML commencent par une structure minimale similaire à celle-ci.

```html
<!DOCTYPE html>
<HTML>

<HEAD>
    <TITLE>Ma première page</TITLE>
</HEAD>

<BODY>

    <H1>Bienvenue</H1>

    <P>
        Mon premier document HTML.
    </P>

</BODY>

</HTML>
```

---

## Bonnes pratiques

!!! tip "Conseil"

    Écrivez toujours votre code de manière lisible.

    Une bonne indentation facilite la lecture, la compréhension et la correction des erreurs.

---

!!! note "À propos du manuel"

    Les exemples présentés dans cette documentation respectent volontairement le style utilisé pendant les travaux pratiques de l'UAM.

    Certaines balises et certains attributs appartiennent au HTML classique. Ils sont conservés afin de rester fidèles au contenu pédagogique du cours.
